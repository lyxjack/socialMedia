# 竞品分析与情报 Skills

## apify-competitor-intelligence — 跨平台竞品情报

- **Slug**: `protoss70/apify-competitor-intelligence`
- **安装**: `clawhub install protoss70/apify-competitor-intelligence`
- **安全**: Benign / Benign
- **版本**: 1.0.1

### 覆盖平台
Google Maps, Booking.com, Facebook, Instagram, YouTube, TikTok — **6 个平台**

### 功能
- 通过 Apify Actors 从 6 个主要平台提取竞品数据
- 分析广告、评论、主页资料、帖子、互动指标
- 灵活输出格式: CSV、JSON、聊天摘要
- 单一工作流替代多个平台独立爬虫

### 配置
```bash
APIFY_TOKEN=    # Apify 账户 token
```

### 使用场景
- Booking.com 竞品评论对标
- Facebook 广告创意和话术监控
- Instagram 互动和粉丝增长对比
- Google Maps 本地竞品评分提取
- TikTok 视频表现趋势分析

### 注意
- 需要 Apify 付费账户
- 数据抓取需遵守各平台 ToS
- 适合 **分析** 竞品策略，不适合大规模数据采集
