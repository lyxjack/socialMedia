# YouTube Skills

## youtube-pro — YouTube 高级分析与转录

- **Slug**: `kjaylee/youtube-pro`
- **安装**: `clawhub install kjaylee/youtube-pro`
- **安全**: Benign / Benign
- **版本**: 1.0.0

### 功能
- 视频转录提取与压缩
- 视频元数据获取
- Gemini AI 驱动的内容分析
- 评论情绪分析
- 特定片段音频/帧下载
- 关键时间戳识别

### 系统依赖
- `yt-dlp`（已安装）
- `ffmpeg`（已安装）

### 使用场景
- 讲座/会议演讲摘要
- 教程字幕文本提取
- 产品评测关键时间戳抓取
- 观众情绪分析（评论区）
- 离线片段下载复查
